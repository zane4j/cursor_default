# 论坛系统 ERD 与 DDL 草案（PostgreSQL）

## 1. 文档信息

- 版本：`v1.0-draft`
- 适用范围：论坛系统 MVP（用户、内容、互动、通知、治理）
- 关联文档：
  - `PRD.md`
  - `ARCHITECTURE.md`
  - `OPENAPI_CONTRACT.md`

---

## 2. 设计目标

1. 对齐 PRD 的业务实体与关系，减少后期频繁改表。
2. 保障核心查询性能（帖子列表、详情、评论、通知）。
3. 支撑治理链路（举报、审核、审计日志）可追踪。
4. 与后端技术栈契合：Spring Boot 3 + JDK 21 + PostgreSQL。

---

## 3. ER 模型（文本版）

核心实体关系如下：

1. `users` 与 `roles` 为多对多，通过 `user_roles` 关联。
2. `categories` 与 `posts` 为一对多。
3. `users` 与 `posts` 为一对多（作者关系）。
4. `posts` 与 `comments` 为一对多。
5. `comments` 自关联（`parent_id`）支持一层回复并预留扩展。
6. `users` 与 `posts` 的点赞关系通过 `post_likes` 表达（多对多）。
7. `users` 与 `posts` 的收藏关系通过 `post_favorites` 表达（多对多）。
8. `notifications` 由 `actor_user_id`（动作人）触达 `target_user_id`（接收人）。
9. `reports` 可指向 `post_id` 或 `comment_id`（二选一）。
10. `audit_logs` 记录管理员/版主关键动作与上下文。

---

## 4. 命名与通用字段规范

### 4.1 命名规范

1. 表名使用复数下划线：`users`, `post_likes`。
2. 主键统一 `bigint`（`GENERATED BY DEFAULT AS IDENTITY`）。
3. 外键命名：`<entity>_id`。

### 4.2 通用字段（建议）

绝大多数业务表包含：

- `created_at timestamptz not null default now()`
- `updated_at timestamptz not null default now()`
- `deleted_at timestamptz null`（需要软删除的表）

备注：

- 本草案默认应用层维护 `updated_at`，如需数据库侧维护可增加 trigger。

---

## 5. 枚举与状态约定（逻辑层）

### 5.1 用户状态 `user_status`

- `ACTIVE`：正常
- `BANNED`：封禁
- `DISABLED`：停用

### 5.2 帖子状态 `post_status`

- `PUBLISHED`：已发布
- `HIDDEN`：下架不可见
- `DELETED`：逻辑删除（冗余态，可与 `deleted_at` 二选一）

### 5.3 评论状态 `comment_status`

- `VISIBLE`
- `HIDDEN`
- `DELETED`

### 5.4 举报状态 `report_status`

- `PENDING`
- `RESOLVED`
- `REJECTED`

### 5.5 举报目标类型 `report_target_type`

- `POST`
- `COMMENT`

## 6. DDL 草案

以下 SQL 以 PostgreSQL 15+ 为基准，编码 `UTF8`，时区 `UTC`（推荐）。

### 6.1 扩展（可选）

```sql
create extension if not exists pgcrypto;
```

### 6.2 角色与用户

```sql
create table if not exists roles (
  id bigint generated by default as identity primary key,
  code varchar(32) not null unique,
  name varchar(64) not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists users (
  id bigint generated by default as identity primary key,
  email varchar(128) unique,
  phone varchar(32) unique,
  password_hash varchar(255) not null,
  nickname varchar(24) not null unique,
  avatar_url text,
  bio varchar(300),
  status varchar(16) not null default 'ACTIVE',
  last_login_at timestamptz,
  banned_until timestamptz,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz
);

create table if not exists user_roles (
  id bigint generated by default as identity primary key,
  user_id bigint not null references users(id),
  role_id bigint not null references roles(id),
  created_at timestamptz not null default now(),
  unique (user_id, role_id)
);
```

### 6.3 板块与帖子

```sql
create table if not exists categories (
  id bigint generated by default as identity primary key,
  name varchar(64) not null unique,
  slug varchar(64) not null unique,
  description varchar(255),
  sort_order int not null default 0,
  is_enabled boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists posts (
  id bigint generated by default as identity primary key,
  category_id bigint not null references categories(id),
  author_id bigint not null references users(id),
  title varchar(100) not null,
  content text not null,
  status varchar(16) not null default 'PUBLISHED',
  view_count bigint not null default 0,
  like_count bigint not null default 0,
  comment_count bigint not null default 0,
  favorite_count bigint not null default 0,
  last_commented_at timestamptz,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz
);

create index if not exists idx_posts_category_created
  on posts (category_id, created_at desc)
  where deleted_at is null;

create index if not exists idx_posts_author_created
  on posts (author_id, created_at desc)
  where deleted_at is null;

create index if not exists idx_posts_status_created
  on posts (status, created_at desc)
  where deleted_at is null;
```

### 6.4 评论

```sql
create table if not exists comments (
  id bigint generated by default as identity primary key,
  post_id bigint not null references posts(id),
  author_id bigint not null references users(id),
  parent_id bigint references comments(id),
  content text not null,
  status varchar(16) not null default 'VISIBLE',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  deleted_at timestamptz
);

create index if not exists idx_comments_post_created
  on comments (post_id, created_at asc)
  where deleted_at is null;

create index if not exists idx_comments_author_created
  on comments (author_id, created_at desc)
  where deleted_at is null;
```

### 6.5 点赞与收藏

```sql
create table if not exists post_likes (
  id bigint generated by default as identity primary key,
  user_id bigint not null references users(id),
  post_id bigint not null references posts(id),
  created_at timestamptz not null default now(),
  unique (user_id, post_id)
);

create index if not exists idx_post_likes_post
  on post_likes (post_id);

create table if not exists post_favorites (
  id bigint generated by default as identity primary key,
  user_id bigint not null references users(id),
  post_id bigint not null references posts(id),
  created_at timestamptz not null default now(),
  unique (user_id, post_id)
);

create index if not exists idx_post_favorites_post
  on post_favorites (post_id);
```

### 6.6 通知

```sql
create table if not exists notifications (
  id bigint generated by default as identity primary key,
  target_user_id bigint not null references users(id),
  actor_user_id bigint references users(id),
  type varchar(32) not null,
  post_id bigint references posts(id),
  comment_id bigint references comments(id),
  payload jsonb,
  is_read boolean not null default false,
  read_at timestamptz,
  created_at timestamptz not null default now()
);

create index if not exists idx_notifications_target_read_created
  on notifications (target_user_id, is_read, created_at desc);
```

### 6.7 举报与审计

```sql
create table if not exists reports (
  id bigint generated by default as identity primary key,
  reporter_user_id bigint not null references users(id),
  target_type varchar(16) not null,
  post_id bigint references posts(id),
  comment_id bigint references comments(id),
  reason_code varchar(32) not null,
  reason_detail varchar(500),
  status varchar(16) not null default 'PENDING',
  handled_by bigint references users(id),
  handled_at timestamptz,
  handle_note varchar(500),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  check (
    (target_type = 'POST' and post_id is not null and comment_id is null) or
    (target_type = 'COMMENT' and comment_id is not null and post_id is null)
  )
);

create index if not exists idx_reports_status_created
  on reports (status, created_at desc);

create index if not exists idx_reports_reporter_created
  on reports (reporter_user_id, created_at desc);

create table if not exists audit_logs (
  id bigint generated by default as identity primary key,
  operator_user_id bigint not null references users(id),
  action varchar(64) not null,
  target_type varchar(32) not null,
  target_id bigint not null,
  before_data jsonb,
  after_data jsonb,
  ip varchar(64),
  user_agent varchar(300),
  request_id varchar(64),
  created_at timestamptz not null default now()
);

create index if not exists idx_audit_logs_operator_created
  on audit_logs (operator_user_id, created_at desc);

create index if not exists idx_audit_logs_target
  on audit_logs (target_type, target_id, created_at desc);
```

### 6.8 Refresh Token（推荐）

```sql
create table if not exists refresh_tokens (
  id bigint generated by default as identity primary key,
  user_id bigint not null references users(id),
  token_hash varchar(255) not null unique,
  expires_at timestamptz not null,
  revoked_at timestamptz,
  created_at timestamptz not null default now(),
  created_ip varchar(64),
  user_agent varchar(300)
);

create index if not exists idx_refresh_tokens_user_expires
  on refresh_tokens (user_id, expires_at desc);
```

## 7. 与 OpenAPI 契约的映射

1. `POST /auth/register` -> `users`
2. `POST /auth/login`、`POST /auth/refresh` -> `refresh_tokens`
3. `GET /categories` -> `categories`
4. `GET/POST /posts`、`GET/PATCH/DELETE /posts/{id}` -> `posts`
5. `GET/POST /posts/{id}/comments` -> `comments`
6. `POST /posts/{id}/like` -> `post_likes` + `posts.like_count`
7. `POST /posts/{id}/favorite` -> `post_favorites` + `posts.favorite_count`
8. `GET /notifications` -> `notifications`
9. `POST /reports`、`GET/PATCH /admin/reports/{id}` -> `reports` + `audit_logs`

## 8. 迁移与版本管理建议

1. 使用 Flyway，采用 `V{version}__{description}.sql`。
2. 基准脚本示例：
   - `V1__init_schema.sql`
   - `V2__seed_roles_and_admin.sql`
3. 任何破坏性变更（删字段、改类型）必须先评审并给出回滚方案。
